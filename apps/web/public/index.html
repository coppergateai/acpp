Trust principles

Identity is not authority.

Three separations that keep agent systems accountable.

Identity ≠ Authority

Knowing which agent is acting does not automatically grant it permission. Every protected action is evaluated against an explicit grant.

who≠may act

Discovery ≠ Consent

Finding an agent or capability does not authorize interaction or execution. Discovery returns only what policy already permits.

find≠consent

Signal ≠ Execution

A signed signal communicates intent or information. Execution requires the authorization path — signals never bypass policy.

intent≠execute

Real-life scenario

A triage agent comments on a GitHub issue.

Your platform team connects GitHub once. An incident-response agent gets a narrow grant to post on issues — not the org token. Every comment leaves a receipt; revoke the grant and the next attempt is denied.

  1. 01

    Ops

    An alert opens issue #4821. Someone needs a status note on the thread — not a human hunting for a shared PAT.

  2. 02

    Agent

    TriageBot sends a signed signal: comment on #4821 with the latest findings.

  3. 03

    ACPP

    Verifies the agent identity, evaluates the grant (issues.comment only), and allows the action.

  4. 04

    GitHub

    The comment posts through the workspace connection. Credential never sits on the agent.

  5. 05

    Receipt

    Audit trail links signal → decision → outcome. Later, security revokes the grant — the next comment returns deny.

Developer experience

A protocol you can build on.

Reference TypeScript SDK in the monorepo (@acpp/sdk). Packages are workspace-private today — clone the repo and run the local API.

TypeScript · docs/protocol/sdk.md 
import { createActorAddress } from "@acpp/core";
import {
  AcppHostedClient,
  generateEd25519KeyPair,
  signSignalEnvelope,
  verifySignalEnvelopeSignature,
} from "@acpp/sdk";

const keys = generateEd25519KeyPair();
const sender = createActorAddress("agent", "MYAGENT01");

const envelope = signSignalEnvelope(
  {
    signalId: "sig_my_request_01",
    type: "request",
    audience: createActorAddress("human", "owner"),
    contentType: "application/json",
    payload: { action: "issues.comment", repo: "org/repo" },
  },
  { sender, publicKey: keys.publicKey, privateKey: keys.privateKey },
);

// Identity proof ≠ permission to act
verifySignalEnvelopeSignature(envelope, keys.publicKey);

const client = new AcppHostedClient({
  baseUrl: "http://127.0.0.1:8787",
});
await client.submitSignal(envelope);
